## ⛏️ Mineflayer Bot
A simple Minecraft Java bot built with JavaScript and [Mineflayer](https://github.com/PrismarineJS/mineflayer).

This is a personal project made to experiment with Minecraft automation, learn more about bots, and mess around with the possibilities of controlling a Minecraft character through code.

Nothing too serious. Just JavaScript, Minecraft, and a few questionable ideas. 👀

## ✨ Features
- 🤖 Connects to Minecraft Java servers
- 💬 Sends messages and commands in chat
- 📡 Listens for chat messages and server events
- 🔌 Handles bot login and connection events
- 🧪 A playground for experimenting with new features

*Features may change as the project evolves.*

## 🛠️ Technologies
- **JavaScript** — the main language
- **Node.js** — JavaScript runtime
- **npm** — package management
- **Mineflayer** — Minecraft bot framework

## 🚀 Getting Started
### 1. Clone the repository
```bash
git clone [repo-link]
cd [repo-name]
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure the bot
Edit the bot configuration in `index.js` to set the Minecraft server address, port, username, and authentication options.

Make sure your account and server support the authentication method you're using.

### 4. Run the bot
```bash
node run help
```

That's it! If everything is configured correctly, your bot should attempt to connect to the server.
